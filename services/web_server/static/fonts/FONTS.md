# Bundled fonts and attribution

The two font files in this directory are third-party open-source fonts, bundled
so the app renders identically offline and on a self-hosted instance. Both are
licensed under the SIL Open Font License, Version 1.1 (OFL-1.1).

| File | Font | Copyright | License |
| --- | --- | --- | --- |
| `InterVariable.woff2` | Inter | Copyright (c) The Inter Project Authors | SIL OFL 1.1 |
| `JetBrainsMono.woff2` | JetBrains Mono | Copyright (c) JetBrains s.r.o. | SIL OFL 1.1 |

Upstream sources:

- Inter: https://github.com/rsms/inter (font and its `OFL.txt`)
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono (font and its `OFL.txt`)

The OFL-1.1 permits bundling and redistribution (including in a commercial,
hosted product) provided the fonts are not sold on their own, the copyright and
license notice travel with them, and no bundled font uses the Reserved Font Name
without permission. The canonical license text is at
https://openfontlicense.org and in each upstream repository above.
